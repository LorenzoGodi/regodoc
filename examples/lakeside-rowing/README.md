# .regodoc package: Records and equipment of the Lakeside Rowing Club

The engine writes this file on every export; it is ignored when the package is read back.

To change the document:

1. edit `structure.toml`, `variables.toml` and the files in `parts/`, one per part;
2. put the images in `images/`, PNG or JPEG only;
3. check the package with `regodoc validate` and rebuild the archive with `regodoc canon`.

The format is described in the `rego/1` specification of the regodoc project.
