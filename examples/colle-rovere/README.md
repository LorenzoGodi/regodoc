# Pacchetto .regodoc: Rinnovo della rete della Cantina Colle Rovere

Questo file lo scrive il motore a ogni esportazione e non conta in importazione.

Per modificare il documento:

1. modifica `structure.toml`, `variables.toml` e i file in `parts/`, uno per parte;
2. metti le immagini in `images/`, solo PNG o JPEG;
3. controlla il pacchetto con `regodoc validate` e ricostruisci l'archivio con `regodoc canon`.

Le regole del formato sono nella specifica `rego/1` del progetto regodoc.
